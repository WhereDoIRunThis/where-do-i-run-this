# Contributing

Help readers find useful places to run applications, agents and compute workloads.

## Suggest an addition or correction

Open an [issue](https://github.com/WhereDoIRunThis/where-do-i-run-this/issues/new) or a [pull request](https://github.com/WhereDoIRunThis/where-do-i-run-this/pulls) with your suggestion. For an addition, include:

- The product name and official website or source repository.
- What readers can run on it, and whether it is hosted, open core or self-hosted.
- A brief factual description and a link to documentation supporting it.

For a correction, identify the product and explain what should change, with a public supporting link when possible. Broken links, renamed products and discontinued services are useful to report too. Please disclose any affiliation with a suggested product.

## What belongs here

The list covers run destinations: services or tools on which readers can execute workloads. Standalone articles, general-purpose libraries without an execution environment, advertisements and promotional copy do not belong here.

Keep suggestions concise and useful. Describe capabilities rather than superlatives, rankings, unverified performance claims or temporary prices. A commercial service is welcome on the same basis as a self-hosted tool; inclusion is not an endorsement.

Maintainers review additions and corrections before including them. Please propose the change and its supporting links in your issue or pull request rather than editing individual list entries directly.
